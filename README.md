# PenBridge

### 1.8.0 멀티 터치 프레임 수정과 작업 화면 정리

- Windows가 한 순간의 모든 활성 손가락을 함께 인식하도록 각 터치 업데이트를 하나의 다중 접점 프레임 배열로 주입합니다. 손가락별로 따로 주입되어 선과 점이 흩어지던 문제를 수정했습니다.
- 웹 설정에서 펜/지우개 도구 선택을 제거하고, 위치 전송 빈도를 원본 입력·240·120·60Hz 중 선택할 수 있게 했습니다. 선택값은 최대 전송 빈도이며 브라우저의 실제 수집 빈도를 높이지는 않습니다.
- 전체 화면 버튼을 제거했습니다. 하단 도구 막대의 화살표로 막대를 접고 다시 펼칠 수 있습니다.
- 상단 연결 상태는 연결·해제 시에만 잠시 나타난 뒤 부드럽게 사라집니다.
- 작업 중 입력값 창에 닫기 버튼을 추가하고 드래그로 이동할 수 있게 했습니다. 위치와 표시 상태는 iPad에 저장됩니다.
- 실행 파일: `PenBridge/publish-1.8.0/PenBridge.exe`. 같은 폴더의 `tools`도 함께 유지하세요.

### 1.7.0 멀티 터치와 손가락 흔적 색상

- 손가락 입력 허용 시 최대 10개의 접점을 각각 독립적으로 추적하며 Windows에 실제 멀티 터치로 전달합니다. 한 손가락을 떼거나 입력이 취소되어도 다른 손가락은 계속 동작합니다.
- iPad 설정의 **손가락 흔적 색상**에서 터치 흔적 색상만 따로 선택합니다. 흔적 형태·크기·사라지는 시간은 펜 설정을 함께 사용합니다.
- 펜 입력은 기존 합성 펜 장치로, 손가락 입력은 별도의 Windows 합성 터치 장치로 전달합니다.
- 실행 파일: `PenBridge/publish-1.7.0/PenBridge.exe`. 같은 폴더의 `tools`도 함께 유지하세요.

### 1.6.0 웹 펜 기능 확장

- iPad 설정에서 펜/지우개, 필압 반응(기본·부드럽게·단단하게·일정), 호버 커서, 작업 중 입력값 표시, 예측 위치 미리보기를 선택합니다.
- 브라우저가 제공하는 축 회전과 지우개/배럴 버튼을 Windows 펜 입력으로 전달합니다. 실제 반응은 펜·브라우저 및 Windows 그림 앱 지원에 따라 달라집니다.
- 펜 입력 진단에서 관측 입력 빈도, 필압, 기울기, 고도/방위각, 회전, 접촉 크기, 접선 압력, 버튼을 확인합니다. 속도·이동 방향은 좌표로 계산합니다. 고정된 기본값을 실제 센서 지원으로 표시하지 않습니다.
- 보안 컨텍스트에서 raw input API가 제공되면 이를 사용하고, 그렇지 않으면 pointermove로 동작합니다. 병합된 중간 좌표를 보존합니다. 예측 좌표는 화면 표시 전용이며 Windows로 보내지 않습니다.
- Apple Pencil의 몸통 더블 탭·스퀴즈·햅틱은 이 웹 버전에서 지원하지 않습니다. 호버·회전·예측 입력도 iPad/Pencil 모델과 Safari가 실제 제공할 때만 동작합니다. 관측 samples/s는 하드웨어 폴링레이트를 보장하지 않습니다.
- 실행 파일: `PenBridge/publish-1.6.0/PenBridge.exe`. 같은 폴더의 `tools`도 함께 유지하세요.

### 1.5.0 iPad 설정과 Windows 시스템 트레이

- Windows 창에는 네트워크·포트, 서버 시작/중지, QR/페어링 관리와 로그를 남겼습니다.
  대상 모니터는 **iPad 설정 → 대상 모니터**, 매핑과 손가락 입력은 기존 iPad 설정에서 변경합니다.
- 창의 닫기(X)와 최소화는 트레이로 숨깁니다. 트레이 아이콘 더블클릭으로 복원하고,
  우클릭 메뉴의 **PenBridge 종료**로 연결 정리 후 완전히 종료합니다.
- 트레이 우클릭 메뉴에서 서버 주소, 연결 클라이언트, 연결 시간, 입력 수, 영상 상태를 확인합니다.
  **연결 상세 정보** 창은 1초마다 갱신되며 브라우저 정보, 마지막 입력 시각, 최근 오류도 표시합니다.
- 연결·해제·오류는 Windows 알림 팝업으로 표시합니다. 반복 오류 알림은 10초 간격으로 제한하고
  최신 오류 내용은 상세 정보에 유지합니다. 트레이 아이콘이 숨겨진 아이콘 영역에 들어가는지와
  알림이 표시되는지는 Windows 작업 표시줄·알림/방해 금지 설정을 따릅니다.
- 모니터 변경은 페어링 토큰과 동일 출처를 검증하고, PC에 실제로 존재하는 모니터만 허용합니다.
- 기존 프로그램을 종료한 후 `publish-1.5.0/PenBridge.exe`를 실행하고 iPad 페이지를 새로고침하세요.
  실행 파일 옆 `tools` 폴더도 함께 유지하세요.

### 1.4.0 가장자리 여백과 펜 흔적

- **설정 → 드로잉 영역 → 가장자리 여백**에서 0/16/32/48/64/96 CSS px를 선택할 수 있습니다.
  영상과 입력 영역이 함께 줄어듭니다. 여백에서 시작한 입력은 무시하고, 진행 중 드래그는 영역 끝으로 제한합니다.
- 펜 흔적은 빛 번짐/연결 선/링/점, 색상, 크기(3~20px), 유지 시간(0.15~1.5초)을 지정하고 저장합니다.
  이 옵션은 iPad의 피드백 표시만 바꾸며 PC 그림 앱의 브러시 설정에는 영향을 주지 않습니다.
- 여백 변경 시 기존 터치 보정은 적용되지 않습니다. 새 영역에서 다시 보정하세요.

### 1.3.0 빠른 필기와 터치 보정

- 접촉 중 이동을 requestAnimationFrame마다 마지막 한 점으로 덮어쓰던 문제를 제거했습니다.
  이동 이벤트는 즉시 전송하고, 지원되는 브라우저에서는 getCoalescedEvents로 중간 좌표와 필압도
  순서대로 전송합니다. 영상 fps와 펜 입력 전송을 분리했습니다.
- 하드웨어의 샘플링 속도를 변경하는 기능은 아닙니다. Safari 버전 및 HTTP/HTTPS 환경에 따라
  중간 좌표 API 지원이 다르므로 실제 곡선 품질은 iPad 실기기에서 확인해야 합니다.
  관련 표준: https://www.w3.org/TR/pointerevents/#coalesced-and-predicted-events
- **설정 → 터치 보정 → 보정 시작**에서 십자 중심 4곳을 누르면 위치 오프셋과 X/Y 비율을 저장합니다.
  보정 중에는 PC 펜 입력이 중지됩니다. 잘못된 점은 저장하지 않으며 초기화·취소가 가능합니다.
- 보정은 같은 모니터 매핑 및 캔버스 크기에서만 적용됩니다. 화면 회전·매핑 변경 후 재보정하세요.
  이 보정은 위치/축 비율 오차를 위한 것으로, 빠른 곡선의 누락 좌표를 복원하는 기능과는 별개입니다.

### 1.2.0 작업 모드와 입력 잠금

- iPad **설정 → 화면 모드**에서 타블릿 화면 / 스트리밍 화면을 선택할 수 있습니다.
- 타블릿 화면은 영상 요청을 취소해 인코더를 종료하고, PC 화면을 보며 펜만 사용하는 패드를 표시합니다.
  스트리밍으로 복귀하면 영상을 다시 연결합니다. 모드는 브라우저에 저장됩니다.
- 하단 **입력 잠금 / 입력 재개**로 펜 전송을 일시 중지할 수 있습니다. 잠금은 페이지를 새로 열면 해제됩니다.
- 모드 전환·잠금 전에 누르고 있던 펜을 해제하며, 타블릿 모드에서는 영상 전용 옵션을 비활성화합니다.
- 유휴 상태의 캔버스 다시 그리기를 줄이고 설정 조회 중복 실행을 방지했습니다.
- 로컬 브라우저에서 영상 중단, 타블릿 모드 저장 후 새로고침 시 영상 요청 없음, 스트리밍 복귀를 확인했습니다.

### 1.1.1 반응 속도 개선

- MP4를 키프레임 단위(약 250ms)로 묶던 전송을 프레임 단위로 변경했습니다.
- 입력 분석 대기 및 화면 축소 처리 비용을 줄였습니다.
- iPad 설정의 **반응 속도 우선**이 기본으로 켜집니다. 재생 대기를 프레임 속도에 따라
  50~133ms로 목표 설정하며, 지연이 조금 늘면 재생 속도를 조절하고 많이 늘면 최신 구간으로 이동합니다.
  불안정한 네트워크에서 끊김이 생기면 이 옵션을 끄면 됩니다.
- 로컬 Edge 브라우저의 20회 표본에서 내부 버퍼 대기는 중앙값 47ms, 최대 90ms였습니다.
  이는 네트워크·화면 획득·인코딩·디스플레이 지연을 포함한 전체 지연 측정값이 아닙니다.
- 프레임 단위 MP4 설정은 https://ffmpeg.org/ffmpeg-formats.html 의 `frag_every_frame`을 사용합니다.

### 1.1.0 실시간 영상과 iPad 설정

- JPEG 주기 조회를 제거하고 FFmpeg H.264 인코더 → 연속 fragmented MP4 → 브라우저 MediaSource 재생으로 변경했습니다.
- 기본값은 가로 최대 1280px / 30fps입니다. iPad 하단 **설정**에서 품질(960/1280/1920px),
  목표 프레임(15/30/60fps), 화면 맞춤, 손가락 입력, 펜 흔적을 변경할 수 있습니다.
- iPad 설정은 해당 브라우저에 저장됩니다. 1.5.0부터 대상 모니터도 iPad에서 선택합니다.
- `publish` 폴더의 **tools 폴더도 실행 파일과 함께 복사**해야 합니다. 별도 설치 없이 함께 제공된
  FFmpeg를 사용합니다. 라이선스와 출처는 `tools/LICENSE`, `tools/NOTICE.txt`를 참고하세요.
- 오디오 전송은 포함하지 않습니다. 실제 프레임과 지연은 PC 인코딩 속도 및 네트워크에 따라 달라집니다.
  브라우저에서 H.264 MediaSource를 지원해야 하며, 미지원 시 설정창에 안내가 표시됩니다.
- 로컬 브라우저에서 실제 화면의 1280×720 연속 재생을 검증했습니다. iPad Safari 실기기에서의
  지연·전력 소모·60fps 달성 여부는 별도 확인이 필요합니다.

### 1.0.1 좌표 수정

Windows 펜 주입 좌표를 전체 가상 화면의 왼쪽 위 기준으로 변환합니다. 주 모니터의 왼쪽이나
위에 디스플레이가 있을 때 해당 오프셋만큼 커서가 밀리던 오류를 수정했습니다.
화면 캡처 좌표는 기존 Windows 화면 좌표를 유지합니다. 프로그램 제목의 `v1.0.1`로
수정 버전 실행 여부를 확인할 수 있습니다.

iPad + Apple Pencil을 Windows용 펜 입력 장치(그래픽 타블릿)처럼 사용하기 위한 Windows 프로그램입니다.
iPad Safari에서 별도 앱 설치 없이 접속하면, Apple Pencil의 위치/필압/기울기를 Windows의
`InjectSyntheticPointerInput` API를 통해 실제 펜 입력처럼 주입합니다.

## 요구 사항

- **Windows**: 10 버전 1809(build 17763) 이상, 64비트(x64). 프로그램 실행 시 자동으로 확인하며,
  조건을 만족하지 않으면 명확한 안내 메시지를 띄우고 종료합니다.
- **iPad**: Safari, Apple Pencil (1세대/2세대/Pro 모두 pressure·tilt 지원).
- PC와 iPad가 **같은 로컬 네트워크(Wi-Fi/LAN)** 에 연결되어 있어야 합니다.

## 실행 방법 (일반 사용자)

1. `PenBridge.exe` 실행 (관리자 권한 필요 없음 — 일반 실행으로 충분합니다).
2. Windows 설정에서 네트워크 어댑터·포트를 확인하고 "서버 시작" 클릭.
3. 화면에 표시된 QR 코드를 iPad 카메라로 스캔하거나, URL을 iPad Safari에 직접 입력.
4. iPad 설정에서 대상 모니터·화면 맞춤·입력 옵션을 선택하고 Apple Pencil로 필기 시작.

연결이 안 될 때는 아래 [문제 해결](#문제-해결)을 참고하세요.

## 개발자용 실행/빌드

```bash
# 개발 실행
dotnet run --project PenBridge

# Win32 P/Invoke 상수·좌표 매핑·상태 머신 등 순수 로직 테스트
dotnet test PenBridge.Tests -c Release

# iPad 클라이언트 입력 순서·캡처 상실·좌표 설정 변경 회귀 테스트 (Node.js)
node --test PenBridge.Tests/client-input.test.cjs

# 실제 Windows API(CreateSyntheticPointerDevice / InjectSyntheticPointerInput) 스모크 테스트
# — iPad 없이도 이 PC에서 Win32 API 자체가 동작하는지 확인합니다.
dotnet run --project PenBridge -- smoketest-injector

# 배포용 단일 실행 파일 빌드 (self-contained, .NET 런타임 설치 불필요)
dotnet publish PenBridge -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o PenBridge/publish
```

## 보안 / 사용 범위

PenBridge는 Windows에 포인터 입력을 직접 주입할 수 있는 프로그램입니다. 이 때문에:

- **신뢰할 수 있는 로컬 네트워크(집/개인 Wi-Fi)에서만 사용하세요.** 공용 네트워크나 인터넷에
  직접 노출하는 것을 기본 사용 방식으로 지원하지 않습니다.
- 서버 실행 시마다 임의의 페어링 토큰이 생성되며, 이 토큰(QR 코드/URL에 포함)을 아는 기기만
  접속할 수 있습니다. 토큰은 디스크에 저장되지 않고, 프로그램 재시작 시 새로 생성됩니다.
- WebSocket 연결 시 Origin 헤더를 검증하여, 다른 웹사이트가 몰래 PenBridge에 접속해 입력을
  보내는 것을 막습니다.
- 한 번에 하나의 iPad 세션만 허용합니다. 이미 연결된 세션이 있으면 새 연결 시도는 거부됩니다.
- Cloudflare Tunnel 등으로 외부에 공개하는 것은 이 프로그램이 공식 지원/권장하는 사용법이
  아닙니다. 부득이하게 사용한다면, 그로 인한 보안 위험은 사용자 본인이 감수해야 합니다.
- 좌표/필압 등 사용자 입력 데이터를 외부 서버로 전송하지 않습니다(텔레메트리 없음). 모든 통신은
  PC와 iPad 사이의 로컬 네트워크 통신입니다.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| iPad에서 접속이 안 됨 | PC와 iPad가 같은 Wi-Fi인지, PenBridge가 "서버 시작" 상태인지 확인 |
| QR 스캔 후 페이지가 안 열림 | URL의 IP가 실제 PC의 Wi-Fi IP인지 확인 (VPN/가상 어댑터 IP가 아닌지) |
| 포트 충돌 | 다른 프로그램이 같은 포트를 쓰는 경우 자동으로 다음 포트를 시도합니다. 로그에서 실제 사용 중인 포트를 확인하세요 |
| 방화벽 경고가 뜸 | Windows Defender 방화벽에서 PenBridge의 "개인 네트워크" 통신을 허용하세요. 프로그램이 방화벽 규칙을 임의로 변경하지는 않습니다 |
| Apple Pencil이 인식 안 됨 | 손가락/마우스는 기본적으로 무시됩니다("테스트용으로 손가락/마우스 입력 허용" 옵션을 켜지 않았다면) |
| 연결이 자주 끊김 | Wi-Fi 신호 확인. iPad 화면 잠금/Safari 백그라운드 전환 시 자동으로 재연결을 시도합니다 |
| Windows 버전 오류 메시지 | Windows 10 버전 1809 이상 필요 (Windows 11 권장) |

## 알려진 한계

- 다중 모니터 수정 후에는 새 `PenBridge/publish/PenBridge.exe`를 실행하고 iPad Safari 페이지를
  새로고침하세요. 실행 중 대상 모니터/매핑 변경은 자동 동기화되며, 변경 중인 스트로크는 해제됩니다.
- 실제 장치 확인: 서로 다른 배율의 모니터에서 네 모서리를 짚고, 빠른 두 번 탭 후 두 번째 탭을
  유지한 채 드래그하세요. Safari 화면 회전/백그라운드 전환 후에도 다음 입력이 가능한지 확인하세요.
- 자동 테스트는 입력 이벤트와 상태 전이를 검증합니다. iPadOS의 실제 제스처 처리 및 Windows
  다중 모니터에서의 체감 동작은 실제 iPad와 연결해서 별도로 확인해야 합니다.

- 실제 iPad + Apple Pencil 하드웨어 없이 검증할 수 없는 부분(Safari의 실제 hover 동작, 실제
  필압 곡선 등)이 있습니다. 자세한 내용은 최종 작업 보고서를 참고하세요.
- ARM64 Windows에서 네이티브로 검증되지 않았습니다 (x64 에뮬레이션으로는 동작할 것으로
  예상되나, 실기기 검증은 하지 않았습니다).
